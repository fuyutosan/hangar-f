# hangar-f
🛸 HANGAR F. ── 第F格納庫。思いついた週に、作る。

## v3 ── 大人の秘密基地（ガレージ）

路地の奥、シャッターの向こう。長押しでシャッターを上げると、3Dのガレージに入れます。
スクロールすると、カメラが部屋を歩いて巡ります。

| 部屋 | 中身 |
| --- | --- |
| 00 ENTRANCE | 布をかぶった次期機体と、ネオンの看板 |
| 01 CONCEPT | 一文字ずつ灯る文章とメーター |
| 02 THE PIT | 主力機3機（触れるデモつき） |
| 03 SCREENING | ブラウン管の前の映写室（紹介映像） |
| 04 CREW | ロッカーと乗組員の社員証 |
| 05 LOGBOOK | パタパタ式の発着案内板＋整備記録（`kiroku.json` を自動転記） |
| 06 B1F | 地下工場の監視カメラ（v2のドット絵工場を移設） |
| 07 PARTS | 部品棚（ステッカー） |
| 08 SAFE | 金庫＝特別格納庫（ダイヤル長押しで解錠） |
| 09 RADIO | 無線室（連絡先）＋シェア |

- **シェア**：右上の `SHARE`、各機体の共有ボタン、無線室、出口から。X / LINE / Facebook / Threads / Bluesky / はてブ / リンクコピー / スマホの共有メニュー。
- **3D**：`v3/garage.js`。three.js（`vendor/three`、MIT）で、床・レンガ・布・ネオン・自販機まで画像素材を使わずコードで生成。重い端末では自動で画質を下げます。
- **音**：`SOUND`（または `S` キー）。雨音・蛍光灯・シャッター・ガレージのラジオ（WebAudioで合成）。
- **仕掛け**：3Dの小物（布・ラジオ・テレビ・ネオン・時計・自販機…）はクリックできます。ロゴ5連打、コナミコマンドも健在。
- **録画用ツアー**：`/?tour` で開くと、シャッターを開けるところから自動で一周します。

### ファイル
- `index.html` … v3 本体
- `v3/app.js` … 画面の動き（シャッター・スクロール・シェア・音など）
- `v3/garage.js` … 3Dガレージ
- `v3/style.css` … 見た目
- `kiroku.json` … 整備記録（大図書館から自動転記）
- `index.v2.html`（`v2.css` / `v2.js`）… 旧・格納庫（v2）
- `index.legacy.html` … 初代（v1）
