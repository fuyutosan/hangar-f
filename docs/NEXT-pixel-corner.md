## 1. 先に直すバグ：PCだとドット絵が止まって見える

### 調査結果
ヘッドレスブラウザ（Chromium）で、1440×900 と 390×844 の両方を確かめた。

| 条件 | 結果 |
| --- | --- |
| PC幅・通常設定 | **動く**（フォークリフト・荷物・クレーンの位置が1.5秒で変化） |
| スマホ幅・通常設定 | **動く** |
| PC幅・**「視差効果を減らす」設定（prefers-reduced-motion: reduce）** | **全部止まる**（アニメーション時間が0.01msになり、全キャラが左端に重なって静止） |

→ **原因はほぼ確実に、PC側のOSが「アニメーションを減らす」設定になっていること。**
`v3/style.css` の末尾にある `@media (prefers-reduced-motion:reduce)` が、すべてのアニメーションを止めている。
v2 にも同じルールがあった。

- Windows：設定 → アクセシビリティ → 視覚効果 →「アニメーション効果」がオフ
- Mac：システム設定 → アクセシビリティ → ディスプレイ →「視差効果を減らす」がオン

**裏付けの見分け方**：この設定が入っていると、PCで開いたときに**入口のシャッターが出ずに、いきなりガレージから始まる**（`v3/app.js` の `if (!TOUR && (RM || ...)) skipGate()`）。
PCでシャッターが出なかったなら、原因はこれで確定。

### 直し方
1. `@media (prefers-reduced-motion:reduce)` の一括停止から、**ドット絵（`#floor` 配下）を外す**。
   ドット絵の「その場で2コマ交互に動く」アニメは、画面が大きく動くわけではないので残してよい。
   - 例：`#floor *, #floor *::before { animation-duration: revert !important; animation-iteration-count: revert !important; }` を reduce の中に追加する
   - 画面を横切る動き（飛行機の離陸、`sortie` キーフレーム）だけは、reduce のときゆっくりにするか止める。
2. B1F に **「▶ 再生／⏸ 一時停止」ボタン**を付ける（`#floor` に `.paused` を付けて `animation-play-state: paused`）。
   - reduce のときは「一時停止」状態から始めて、押せば動く、でもよい。こちらの方が丁寧。
3. 確認すること：Playwright で `reducedMotion: 'reduce'` を指定し、`.fl-fork` の位置が時間で変わること。
   - 調査に使ったスクリプトの考え方：1.5秒あけて `getBoundingClientRect().x` を2回取り、比べる。

## 2. 新しいコーナー案（全部やる）

おすすめの順番：**1（バグ）→ A → B → D → C → E**
A と B だけで「上はおしゃれ・下はかわいい、二階建ての秘密基地」が完成する。
C〜E は、余力に応じて足していく。

### 使えるドット絵（`assets/px/`）
- メイメイ：`mei_walk_a/b`（歩き）・`mei_guide_a/b`（誘導）・`mei_desk_a/b`（PC作業）・`mei_bite_a/b`（笹）・`mei_pc`・`mei_rest`
- 乗組員：`welder_a/b`（溶接）・`painter_a/b`（塗装）・`mech_a/b`（整備）・`marshaller_{blue,green,red}_{A,B}`（誘導員）
- 乗り物：`plane_long/short`・`plane_gold_long/short`・`forklift_a/b`
- 背景・小物：`hangar`・`machine_a/b/ctrl/pc`・`belt_l/m/r`・`crate_a/b`・`barrel`・`hook`・`pole`・`beacon_red/blue`・`sign_warn`・`girder_*`・`pillar`・`panda_face`
- 全部 `image-rendering: pixelated` で拡大すること（整数倍がきれい）。

### 案A：案内係メイメイ（最優先）
**一言で**：ドット絵のメイメイが画面の下をトコトコ歩いてついてくる。部屋を移るたびに歩いて移動し、吹き出しでひとこと言う。

- 置き場所：`index.html` に固定要素 `<div id="guide" aria-hidden="true">` を追加（画面下・左寄り、z-index は `.spots` より上、モーダルより下）。
- 動き：`v3/app.js` の `onSection(el)` が呼ばれたら
  1. `mei_walk_a/b` を 0.13 秒ごとに切り替えながら、横に 120〜200px 歩く
  2. 止まったら部屋ごとのポーズに切り替える（下の表）
  3. 吹き出し（CSS）でセリフを 3 秒出す
- 部屋ごとのポーズとセリフ（たたき台。ふゆとと調整する）

| 部屋 | ポーズ | セリフ |
| --- | --- | --- |
| ENTRANCE | guide | 「ようこそ！奥へどうぞ」 |
| CONCEPT | rest | 「布の下は、まだ秘密です」 |
| THE PIT | desk | 「この3機、触れますよ」 |
| SCREENING | rest | 「ソファでどうぞ」 |
| CREW | guide | 「わたしのロッカーもあります」 |
| LOGBOOK | desk | 「パタパタ、好きなんです」 |
| B1F | walk→下へ消える | 「地下はわたしの職場です！」 |
| PARTS | bite | 「ステッカー、貼ってね」 |
| SAFE | guide | 「長押しですよ」 |
| RADIO | rest | 「感想、待ってます」 |
| EXIT | guide（手を振る） | 「また来てね！」 |

- クリックすると、ランダムなひとことと `Snd.blip()`。ロゴ5連打のオーバードライブ中は走る（コマ切り替えを速く）。
- 出さないとき：入口のシャッター中、モーダル表示中、`?tour` のときは任意（録画で映えるなら出す）。
- スマホ：大きさを 0.75 倍にして、シェアボタンや本文に重ならない位置にする。
- `prefers-reduced-motion`：歩かずに、その場でポーズとセリフだけ切り替える。
- 作業量の目安：小（JS 60〜100行＋CSS）

### 案B：地下へ降りるエレベーター（B1F を「部屋」に格上げ）
**一言で**：ハッチ（3D）か B1F のボタンを押すとエレベーターで降りて、画面全体がドット絵の地下工場になる。

- 入口：
  - 3D：`garage.js` の `pickables.hatch` をクリックした時（今は `goTo('#b1f')`）
  - HTML：B1F セクションに「▼ 地下へ降りる」ボタン
- 演出（全画面オーバーレイ `#b1f-world`）：
  1. 3Dカメラがハッチを見下ろして沈む（`garage.js` に `descend()` を追加：goalP.y を 0 付近へ）
  2. 画面が暗転し、階数表示「1F → B1F」がパタパタ（既存の `flapCell` を流用）
  3. ドット絵の工場が**全画面**で現れる。今の `#floor` をそのまま全画面に広げる（`--s` を画面の高さに合わせる）
  4. 背景を足す：`girder_*`・`pillar` で天井と柱、奥に `hangar`
- 地下では：
  - 横スクロール（ドラッグ／ホイール）で工場の端から端まで見られる
  - キャラをクリックすると名札（「溶接班：火花良好」など、CCTVのティッカーの文言を流用）
  - 「▲ ガレージへ戻る」で上がる（`Esc` でも戻る）
- 音：エレベーターのモーター音は `Snd.motor()` を流用、到着で「チーン」（`Snd.tone`）。
- 作業量の目安：中

### 案C：ゲーム筐体コーナー
**一言で**：ガレージの隅にレトロなゲーム筐体を置き、メイメイのミニゲームで遊べる。

- 3D：`garage.js` に筐体を追加（箱＋斜めの画面＋操作パネル）。置き場所は左奥（ロッカーとハッチの間あたり）が空いている。
  - 画面は `CanvasTexture` で、待機中はタイトル画面「MEIMEI CATCH ／ INSERT COIN」を点滅させる。
  - `pickables.arcade` に登録し、クリックでゲームを開く。
- ゲーム（全画面モーダル、canvas 2D）：
  - 「笹キャッチ」：上から笹（緑）とレンチ（グレー）が落ちてくる。メイメイ（`mei_walk`）を左右に動かして笹だけ取る。30秒勝負。
  - 操作：←→キー／画面の左右タップ／ドラッグ
  - ハイスコアは `localStorage`（自分の端末だけ）
  - 結果画面に「スコアをシェア」→ 既存の `openSheet({name, title, text, url})` に渡す
- 作業量の目安：中

### 案D：フィギュア棚（乗組員の図鑑）
**一言で**：ガラスケースにドット絵キャラを並べた「コレクション」。カーソルを乗せると名前と担当が出る。

- 置き場所：「04 CREW」の下か、新しい小さなセクション「04.5 COLLECTION」。
- HTML/CSS だけで作れる：棚板3段、各マスに2コマアニメのキャラ、ガラスの映り込み（グラデーション）、下に真鍮の名札。
- 図鑑の中身（たたき台）：メイメイ（休憩・作業・誘導）／溶接工／塗装工／整備士／誘導員（青・緑・赤）／フォークリフト／パンダ号（飛行機）／金のパンダ号（レア：ロゴ5連打で出る機体）
- 「金のパンダ号」は最初シルエットで、隠しコマンドを見つけると解放（`localStorage`）。集める楽しさが出る。
- 作業量の目安：小〜中

### 案E：ドット絵モードのスイッチ
**一言で**：壁のスイッチを押すと、3Dガレージがまるごとドット絵風（低解像度＋ディザ）の見た目になる。v2 の回廊の質感の再来。

- `garage.js` の `gradePass`（最後のシェーダー）に `uPixel` を足す：
  - 画面を 1/4〜1/6 の解像度で拾う → 色数を減らす → ベイヤーディザ（v2 の `v2.js` の `bayer()` をそのまま移植できる）
- 低画質モード（composer なし）のときは、レンダラーの `setPixelRatio` を小さくし、canvas に `image-rendering: pixelated` を付ける簡易版にする。
- スイッチは3Dの壁（入口横）＋ヘッダーの小ボタン「8BIT」。状態は `localStorage` に保存。
- 案Aのメイメイ・案Bの地下と組み合わせると、全部がドット絵の世界になる「裏モード」になる。
- 作業量の目安：小

## 3. 作業の約束ごと（v3 の作り方に合わせる）

- ファイル：`index.html`／`v3/app.js`（画面の動き）／`v3/garage.js`（3D）／`v3/style.css`。新しい大きな機能は `v3/pixel.js` に分けてもよい（`app.js` から `import`）。
- 画像素材は増やさず、既存の `assets/px/` を使う。足りない絵が必要なら、ふゆとに相談する。
- `prefers-reduced-motion`、キーボード操作（Enter／Esc）、スマホのタップは毎回確かめる。
- `?tour`（録画用ツアー）に新しいコーナーを1カ所ずつ足す。
- 確認方法（このリポジトリでやってきたやり方）：
  - `npx http-server -p 8080 -c-1 -s .` で配信
  - Playwright（Chromium、`--use-angle=swiftshader`）で PC 1440×900／スマホ 390×844 を撮影して目で見る
  - 3Dは仮想環境だと 1〜3fps しか出ないので、撮影前に `HF.sync()`（カメラを目的地へ即移動）を呼ぶ
- 完成したら、`README.md` の部屋一覧にコーナーを追記する。
